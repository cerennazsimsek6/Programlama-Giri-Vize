# Türk Masalları Derlemesi

## Programlamaya Giriş Güz Vize Ödevi

**Öğrenci:** Ceren Naz Şimşek  
**Öğrenci Numarası:** 86250002

### Proje Hakkında

Bu proje, Türk masallarını dijital ortamda bir araya getirmek amacıyla hazırlanmıştır. Web sitesinde farklı Türk masallarına yer verilmiş, masallar renkli ve illüstrasyon ağırlıklı bir tasarımla sunulmuştur.

Projede HTML, CSS ve JavaScript kullanılmıştır. Kullanıcılar masal adlarını veya masallarla ilgili kelimeleri arama bölümünden arayabilir ve masalları inceleyebilir.

## Dosyalar

- `index.html` → Web sayfasının HTML yapısını içerir.
- `style.css` → Web sayfasının görsel tasarımını düzenler.
- `script.js` → Arama, kategori filtreleme ve kullanıcı etkileşimlerini sağlar.
- `86250002_cerennazşimşek_vize.pdf` → Proje raporudur.
- `main (1).tex` → Raporun LaTeX kaynak dosyasıdır.
