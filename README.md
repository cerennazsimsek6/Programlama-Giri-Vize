### Proje Hakkında

Bu proje, Türk masallarını dijital ortamda bir araya getirmek amacıyla hazırlanmıştır. Web sitesinde farklı Türk masallarına yer verilmiş, masallar renkli ve illüstrasyon ağırlıklı bir tasarımla sunulmuştur.

Projede HTML, CSS ve JavaScript kullanılmıştır. Kullanıcılar masal adlarını veya masallarla ilgili kelimeleri arama bölümünden arayabilir ve masalları inceleyebilir.

### Dosyalar

- `turk_masallari_son_kontrol.html` → Projenin ana web sayfasıdır.
